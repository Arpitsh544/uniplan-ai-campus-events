UniPlan AI - Shared Laptop Demo
===============================

Start the shared server on the laptop that will host the demo, then open the LAN address printed by the server on the other laptops. All laptops must be connected to the same Wi-Fi/LAN.

Windows:
1. Install Node.js on the host laptop if it is not already installed.
2. Open a terminal in this folder.
3. Run: node server.js
4. On each laptop, open the LAN URL printed by the server, for example http://192.168.x.x:8787
5. If Windows Firewall asks, allow Node.js on the Private network.
